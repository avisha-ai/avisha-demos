Spotting the one test that behaved differently

Demo with illustrative, simulated data. Not real test results, not a safety assessment.

Repeat adiabatic tests of the same material should look alike. When one of them doesn't, that is the test an engineer should look at first.

Below: twelve simulated tests of one material. Eleven agree with each other. One does not.

2. Self-heat rate against temperature

Flag: Run 8

What changed

  • Onset (self-heat rate passing 0.02 °C/min) at 55.6 °C, about 9 °C below the normal range of 64.4–64.7 °C.
  • Peak self-heat rate reached after 9.9 hours, against 23.4–28.0 hours for the normal runs.
  • Highest self-heat rate 79 °C/min, against 30–33 °C/min for the normal runs; the final temperature is about the same (203 °C).

Possible reasons an engineer would check: sample batch or contamination, sample mass/fill, test cell, or set-up.

A flag shows what changed. It does not establish why.

How the data was made

Simulated, illustrative only. One first-order reaction under adiabatic conditions (Arrhenius kinetics, phi = 1, illustrative): activation energy 100 kJ/mol, adiabatic temperature rise 150 °C, start about 54 °C (±1 °C between runs), small run-to-run variation in reaction speed (±2%). Run 8 reacts 2.5 times faster, as a small catalytic impurity might cause. Each run is calculated step by step until 99% of the material has reacted. The onset threshold of 0.02 °C/min is an illustrative detection threshold. No real material, instrument or test is represented.
