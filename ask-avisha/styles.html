Ask Avisha: style reference (v4)

Design reference for the Ask Avisha demo. The samples below are pictures, not buttons. Rule: one primary, one secondary, one assistant launcher; calm surfaces (8–12 px corners, light shadows, no gradients except the assistant launcher, minimal motion).
